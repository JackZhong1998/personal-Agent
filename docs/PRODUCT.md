# Between · ROSÉ 平行心动

## 定位

以 BLACKPINK 的 ROSÉ 为角色的非官方虚构同人语音故事。用户在一个平行故事里，从意外相遇、日常分享、暧昧试探走向告白与恋爱日常。所有对话、经历、关系和图片都是创作，与本人及所属团队无关联。使用服务端配置的合成配音，不宣称是 ROSÉ 本人的原声、私聊或真实经历，不创建新的明星声线。

英语是相处时使用的语言，页面不把互动包装成课程、面试或考试。台词包含口语、停顿、逗趣、撒娇和温柔表达，没有口语打分。沿用已确认的**固定剧本、录完即推进**，不调用 LLM、不做语音识别或依据用户说话内容自动改写。

## 内容规模

12 章，每章 20 次用户回应、21 段角色语音（含收尾）、3 条场景图片消息。共 240 次互动、252 段预写角色台词与对应中文翻译、480 条可选英文回应。图片使用 10 张仓库内的场景插画；没有伪装为本人拍摄的私密照片。

## 首次流程与称呼

首页 → 开启第一章 → 必填“她应该怎么称呼你”（1–20 个字符，可中文或英文）→ 成年与虚构剧情/录音保存确认 → 保存服务端个人称呼 → 场景简介 → 用户主动开始才合成首句。

名字保存到匿名用户的服务端 profile 和当前对话快照；在指定台词中替换 `{{name}}`，英文声音与中文翻译使用相同称呼。角色不是只在页面标题上叫用户名字。修改称呼后，新章节或重开的对话生效；历史与正在进行的章节保留原称呼。姓名只作变量代入，不重新生成剧情。

含名字的角色音频存入用户私有缓存路径；同名的不同用户不共享该类音频。其余不含个人信息的固定素材可共享内容缓存。

## 沉浸式对话页

桌面为深色故事侧栏 + 独立聊天窗口；手机为全屏聊天。黑粉/玫瑰色视觉，顶部角色与虚构标识、实时关系栏、当前章节进度固定显示，底部录音操作固定，中间消息记录独立滚动。

- 对方语音使用左侧头像、波形气泡；自己的录音使用右侧气泡、昵称、秒数和送达标记。
- 每段角色语音下有“查看第 N 段中文”。点击才向服务端读取该条已到达台词的翻译，支持收起、再次展开。不会调用翻译模型或语音合成；不能提前读未到达的台词。
- 剧情推进时插入场景插画消息，有手写感说明、插画标识，可点击放大，支持关闭与键盘操作。
- 点麦克风开始，再点结束发送。成功保存录音与下一句角色音频后再推进，不自动重发失败录音；失败保留待发送内容供用户显式重试。页面切后台即停止并丢弃尚未发送录音。
- “怎么回”提供当前轮的两条口语灵感，读音按钮点击后才使用 edge-tts；用户仍只发送录音。
- 每章 20 次用户回应后收尾，可在回忆页重听完整消息历史和自己的录音。

固定剧情不会理解用户录音，因此不声称能依据说话内容记住偏好、判断表白答案或生成个性化聊天。剧情中的询问仍是预写台词。用户可随时暂停退出。

## 每次互动的数值反馈

| 行为 | 熟悉度 | 心动值 | 星光 |
| --- | --- | --- | --- |
| 首次完成某章某轮互动 | +2 | +1 | +5 |
| 在新会话里再次完成同一轮 | 0 | 0 | +1 |
| 重复 HTTP 提交、只重听、查看翻译/图片 | 0 | 0 | 0 |
| 当天前两章首次完结 | 0 | 0 | 每章额外 +10 |

每天两章是温柔目标，额外互动仍有逐轮奖励。日界以 Asia/Shanghai 零点切换，缺席不扣分、不重置。熟悉度最高 480、心动值最高 240，完整首次通关可填满；星光可通过重温继续积累。

五个故事阶段按熟悉度：0 初次相遇，80 渐渐熟悉，200 心动试探，320 双向靠近，440 我们的日常。数值代表虚构故事参与，不代表真实艺人的情感或对用户的评价。

反馈在当前消息下保留一条获得记录；新互动成功时，顶部常驻数值更新、进度条平滑推进、数字弹入、聊天边框单次亮起、爱心与星光粒子散开，加分卡显示本次收益。跨阶段时显示升级提示。遵循 reduced-motion 系统设置，无快速频闪。恢复会话不重复播放领取动画。

结算在服务端加锁执行，以“会话 ID + 轮次”去重。录音已保存但结算中断时，重试/恢复会话会补齐缺失奖励；已发过的奖励不重复发。

## 存储与部署

继续使用既有 Supabase 表与私有音频 bucket，不需要新增 SQL。新故事进度键为 `rose-parallel-v1` 命名空间；原 Alex 版的会话、录音和缓存保留在后台，不混入新剧情，也不直接续聊旧剧本。

主应用部署到 Vercel；环境变量保持原有配置，角色语音仍按当前设置的 Cartesia 模型与 voice ID 使用，不自动变更或预生成。Render 的 Python edge-tts 服务、免费配置与自动生成密钥保持原方案。静态图片随代码部署，无额外图片服务或在线生图费用。
