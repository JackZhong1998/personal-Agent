# Between 之间：产品与交互设计

## 核心体验

以英语练习为起点的语音故事陪伴产品，移动优先、桌面自适应。首版采用**完全预写的固定剧本**，用户录音结束后顺序推进，不调用 LLM、不识别用户说了什么、不根据录音内容改写回复。这里的「熟悉」是剧情和参与进度，不是系统真的理解并记住了用户说的话。

所有对话角色为成年人。Alex 为虚构的 26 岁书店设计师，是示例角色；形象、姓名和台词不代表克隆声音原主人的真实身份。用户提供的克隆声音绑定于 Cartesia 的 voice ID。当前全部 12 章为可替换的示例内容，并非用户已提供的正式剧本。

## 页面结构

| 页面 | 用户看到什么 | 关键动作 |
| --- | --- | --- |
| 今日相伴 | 今日问候、故事主视觉、最近两个章节、每日两章进度、Alex 介绍 | 开启/继续章节、查看全部故事 |
| 我们的故事 | 12 个场景卡片，显示可开始/已完成/未解锁 | 按顺序进入；已完成可重新练习 |
| 章节准备弹窗 | 场景插画、故事介绍、四轮互动说明、声音保存说明 | 主动点击后才开始首次角色 TTS |
| 语音对话页 | 场景、Alex 的语音气泡、用户录音回放、当前中文表达任务 | 听声音、点麦克风开始，再点结束并发送 |
| 表达提示 | 当前轮两条预写英文建议及独立读音按钮 | 看提示/听读音；不会代替用户发送文字 |
| 完成页 | 章节完成、保存回忆提示 | 返回首页或下一章节 |
| 回忆收藏 | 完成日期与场景卡 | 打开最近一次练习，重听角色声音与自己的录音 |
| 关系旅程 | 熟悉度、心动值、四个阶段、成长规则 | 了解成长，保持自主节奏 |
| 个人设置 | 昵称、友好/心动偏好、服务配置状态 | 保存当前浏览器偏好 |

桌面为左侧导航 + 主内容 + 右侧每日目标。手机为单列内容 + 固定底部四栏导航；语音页使用独立布局，录音按钮不会被底部导航遮挡。不实现登录和支付。

## 用户主流程

1. 首页 → 点击「开启第一章」。未操作时不生成任何音频。
2. 首次使用弹窗 → 昵称、友好/心动期待、成年与录音保存确认 → 继续。
3. 场景准备 → 看章节简介 → 点击「进入语音章节」。
4. 服务端读取本章第 1 句预写台词 → 查缓存 → 未生成时才调用 `sonic-3.6` + 指定 voice ID → 保存音频和文本 → 播放。浏览器阻止自动播放时，手动点播放按钮。
5. 听完 → 可展开当前轮的英文表达提示。只有点某一条读音按钮才调用 `edge-tts`，结果同样缓存。
6. 点麦克风 → 浏览器请求权限 → 说 1–45 秒 → 再点结束 → 保存用户录音 → 进入下一句固定角色台词。
7. 重复四轮 → 播放固定收尾台词 → 首次完成结算 → 保存到回忆 → 解锁下一章。
8. 完成当天前两章后可继续额外章节，但不增加当日成长值；也可退出，第二天继续。

中途退出可从最近保存的轮次继续。录音上传/语音生成失败时显示错误并保留本次待发送录音供显式重试；未成功的请求不会在后台自动重发。切到后台会停止并丢弃当前尚未发送的录音，返回后重新录制。退出或刷新会丢弃浏览器内尚未发送的重试录音。

## 数值设计

| 数值 | 每日规则 | 上限 |
| --- | --- | --- |
| 熟悉度 | 当天首次完成的前两章，每章 +10 | 100 |
| 心动值 | 当天首次完成的前两章，每章 +6 | 100 |
| 每日小约定 | 两个不同章节首次完成，点亮 2/2 | 2 |
| 重复练习 | 保存新的练习录音，不再给成长值 | 无额外奖励 |

每日以 Asia/Shanghai 零点切换。缺席不扣分、不清零。额外章节首次完成时奖励为 0，之后重练不会补发该章奖励；界面规则应明确。数值由服务端结算，同章重复请求不重复领奖，同一天第三章起不给积分。前端不可以直接提交加分数值。

阶段按熟悉度推进：0「初次相遇」、20「渐渐熟悉」、50「心动之间」、80「双向喜欢」。数值不强迫用户进入恋爱，也不充当情感或英语能力评价。友好/心动偏好仅影响界面说明，**当前固定剧本不会根据该偏好分支**；如正式内容要有独立友谊路线，应编写对应的预设剧本。

## 示例内容安排

1. 街角咖啡馆：自我介绍、饮品、一天的开始、兴趣。
2. 黄昏街道：街区、放松方式、理想的夜晚。
3. 午休天台：工作、小成就、下班后的期待。
4. 雨天书店：书、音乐、家与回忆。
5. 周末市集：食物、做饭、周末习惯。
6. 睡前电话：梦想、小目标、温柔告别。
7. 唱片店：分享音乐、表达好感、尊重节奏。
8. 公园：简单表达感受、说出当下需要。
9. 河畔晚餐：关系探索，也允许友谊与放慢。
10. 熟悉的咖啡馆：回顾、习惯与小传统。
11. 傍晚河边：表达心意、偏好与边界。
12. 周末阳台：回顾口语进步，规划下一段日常。

编辑入口：`lib/story.ts` 为章节元信息；`lib/scripts.ts` 为五句角色台词、四轮中文引导与英文建议。修改台词后更新 `SCRIPT_VERSION`，避免旧会话与新剧本错位。正式内容可直接按相同结构替换，不需要 LLM。

## 明确的首版边界

- 不做口语识别、发音评估、语义判断或智能分支；浏览器只做基础时长和音量门槛，噪音也可能通过，不能用于考试评分。
- 固定台词不会认识用户昵称，也不会根据用户录音中透露的信息回答。界面不假装存在动态记忆。
- 无账号，匿名 Cookie 是当前设备记录的访问凭证；清除 Cookie 无法找回，不支持跨设备。
- 长期剧情可继续扩展。首版 12 章完成后主要体验为回顾和重练，尚无自动生成后续章节。
- 缓存的是固定台词和读音素材；用户录音以独立私有路径保存。不会为缓存而预先批量调用 TTS。
